# Yaw连续转动

2026-10-11：用户确认Yaw机构无止挡、线缆不会缠绕，默认开启
`GIMBAL_YAW_CONTINUOUS_ROTATION=1`。取消Yaw行程故障、边界减速、
目标角度夹紧和向外输出拦截；速度/加速度/输出限幅及位置保持保留。
Pitch行程和全部反馈健康检查、故障锁存及重新准备流程保持原样。
设该宏为0可恢复原Yaw ±90°软限位、±100°硬限位。

IMU适配器已逐次累加最短角度差，电机驱动已累计编码器圈数；继续使用这些
连续角度，避免跨±180°或编码器0/8191时目标/反馈突变。USB文本的yaw_deg
仍是INS原始包络角，可跳变；VOFA ch0/ch1是连续目标/实际角，ch10是角度误差。

## 验证

主机测试覆盖正反多圈、实际适配器输入INS包络角与多圈电机角、跨圈连续性、
中立位置抗扰动保持、Pitch限位、非有限值与超速故障。主机模拟不代表实机动态效果。

已通过8组主机测试及sentry/infantry从新目录完整编译，产物位于
`build/yaw-continuous-sentry-20261011/`和`build/yaw-continuous-infantry-20261011/`。
修改模块无新增编译警告；其他模块保留原有未使用变量/函数与CRC const警告。

硬件验证待用户烧录执行：DM-MC02，Yaw CAN1 ID1、Pitch CAN2 ID2 GM6020，
BMI088随Pitch，UART5遥控，USB文本日志。

1. 两拨杆下档，右摇杆回中，上电静止等待IMU校准；确认fault=0。
2. 左拨杆下档选双轴，右拨杆上档；先小幅左右确认方向。
3. 右摇杆横向小行程保持，Yaw转过一整圈后回中，观察停车和保持；反方向重复。
4. 观察fault=0、axis_mask=3；回中后轻推再放开，目标位置应保持而非跟随手推。
5. 验证Pitch上下仍可控制，端点仍减速；复制完整日志反馈。异常时右拨杆下档停止。

实机尚未验证跨圈处的抖动及长时间Yaw漂移；此次未改变PID、输出上限或遥控映射。
