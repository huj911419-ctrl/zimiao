# GM6020 遥控云台调试

当前双轴操作见 [双轴遥控与保持](dual_hold_bringup.md)，历史逐步流程见 [遥控器验证与单轴控制](remote_bringup.md)。上电默认 stage=2，
已删除自动正弦和固定电压测试旁路；USB 文本新增遥控输入字段。
鼠标键盘输入已预留但默认关闭，配置与接入条件见[键鼠控制说明](../cmd/gimbal_key_mouse.md)。

当前临时通过 USB 打印 IMU 文本，发送 `imu 0`（带换行）恢复原 VOFA+ 波形。
USART10 输出仍保留，接线和动作顺序见 [采集说明](imu_uart_capture.md)。

本版本用于 DM-MC02 / STM32H723，两台 GM6020，IMU 随 Pitch 和相机支架一起运动。
上电须右拨杆下档、摇杆回中准备，再显式使能；手动采集 IMU 时先发送 `stop`。
所有硬件方向、增益和机械限制都需要实机验证。
未接入底盘、发射或视觉控制；sentry、infantry 使用同一套云台运行逻辑。

## 构建与第一版默认行为

先创建 `build`，随后运行 `make -j8 ROBOT=sentry` 或 `make -j8 ROBOT=infantry`。
未指定 ROBOT 时默认 sentry。产物在 `build/<robot>/`，没有自动烧录步骤。

集中配置：`application/gimbal/gimbal_manual_config.h`。
VOFA+ 连接、通道表与在线调参流程见 [vofa_tuning.md](vofa_tuning.md)。

| 配置 | 默认 | 含义 |
|---|---|---|
| GIMBAL_CONTROL_STAGE | 2 | 上电准备角度保持与速度前馈，仍须 RC OFF/回中后拨上档才使能；`stop` 切到0 |
| GIMBAL_USB_IMU_TEXT_DEFAULT | 1 | 临时上电打印 USB 文本；`imu 0` 恢复 VOFA+，`imu 1` 返回文本 |
| stage=1 | VOFA+ 发送 `stage 1` | 仅角速度 PI，供单轴速度环调试；中档为零速度，不是姿态保持 |
| stage=2 | 上电默认或发送 `stage 2` | 角度 P + 速度前馈 → 角速度 PI，遥控回中保持 |
| GIMBAL_MOTOR_OUTPUT_ENABLED | 1 | 总输出开关；置 0 等价于观测阶段 |
| Yaw / Pitch 最大遥控速度 | 240 / 120 deg/s | 内部转为 rad/s；Pitch端点余量区退出另限30 deg/s |
| Yaw / Pitch 目标加速度 | 720 / 360 deg/s² | 限制摇杆目标变化，并用于边界减速 |
| Yaw / Pitch 输出上限 | 15000 / 15000 | GM6020 CAN 电压命令单位，不是电流或 Nm |
| Yaw 角度 Kp / 速度 Kp / Ki | 8 / 24000 / 15000 | 增加姿态纠偏，速度增益保留 |
| Pitch 角度 Kp / 速度 Kp / Ki | 4 / 10000 / 9000 | 降低振动引起的纠偏，保留输出上限，待实机验证 |
| Yaw / Pitch 积分输出限幅 | 5000 / 8000 | 已乘 Ki 的积分输出项限幅 |

观察模式用 `stop` 进入0；单轴速度环调试可用1。当前默认2省去每次上电的串口开始命令。
切阶段和改参数前遥控回右下档、右摇杆回中。
阶段和在线参数只保存在 RAM；重启恢复配置文件值。不要把原来 degree 输入的 PID 系数直接搬进来。

## 接线与操作

- Yaw：FDCAN1，物理电机 ID1，反馈 0x205。
- Pitch：FDCAN2，物理电机 ID2，反馈 0x206。
- 遥控：DT7/DR16 接 UART5 RX（当前 CubeMX 配置为 PD2），共地，100000 baud / 8 数据位 / 偶校验 / 1 停止位；HAL 表示为 9B+EVEN。
- USB CDC：上电默认 IMU/遥控文本，发送 `imu 0` 恢复 VOFA+ 100 Hz JustFloat。

| 拨杆 | 下档 | 中档 | 上档 |
|---|---|---|---|
| 右拨杆 | 零输出 / 重新准备 | 保持进入时的姿态（stage=2） | 右摇杆控制 yaw/pitch 转速 |
| 左拨杆 | 双轴 | 仅 Pitch | 仅 Yaw |

解码开关值为 UP=1、DOWN=2、MID=3。先逐个操作确认：
VOFA+ ch15 左拨杆下/中/上对应轴掩码 3/2/1；ch46 右拨杆对应 OFF/HOLD/MANUAL 请求 0/1/2。
ch47=1 表示右摇杆回中（当前死区 80 counts）。USB 文本 v2 末尾也直接打印拨杆和摇杆值。

每次上电、发生故障、切换左拨杆选择的轴之后，必须：

1. 右拨杆回下档，右摇杆回中；反馈健康，所选轴位于软限位内。
   stage=1/2 的 Pitch 另允许在硬边界内的端点余量区准备，向内推杆低速退出。
2. stage=1/2 时观察 `state=1`（READY）。
3. 保持摇杆回中，将右拨杆拨到中档或上档。

禁止带着偏转的摇杆从 OFF 直接使能。故障消失后仍需回下档重新准备，不会自动续跑。
未选中的轴始终零输出；单测 Yaw 时，应支撑好没有驱动力的 Pitch 机构。
两个电机都应保持供电与通信，即使只选择一个轴。

## IMU 验证与方向配置

上电静止完成在线标定；标定失败退回默认零偏时 `cal=0`，控制禁止使能。
保持静止重新上电；不要用调大 PID 的方式绕过 IMU 故障。

stage=0 下手动分别转动两轴，记录：

- ch18 IMU 反馈年龄很小，ch17=1，ch37 控制快照时间连续增长。
- ch44/ch45/ch40 依次为 INS Yaw、Pitch、Roll，单位 deg。
- ch41..43 是安装变换后的 X/Y/Z 角速度，单位 deg/s。
- ch35/ch36 编码器与两轴方向变化一致，静止时角速度接近零。

本项目将绕 X 的欧拉角称为 Pitch，绕 Y 的称为 Roll；不要按变量英文名猜轴。
默认安装变换为零；若手动俯仰主要改变 Roll，应先调整安装或
`GIMBAL_IMU_MOUNT_*_DEG`，使相机俯仰对应 INS Pitch，再调闭环。
该安装变换对初始四元数和运行期 gyro/accel 均生效。
控制器使用与这套欧拉角定义一致的角速度变换；Pitch 倾斜后不会简单把 Gyro[2] 当航向速度。
INS Roll 超过 ±60° 时拒绝控制，避免欧拉角奇异区域。

三个方向配置要分开理解：

| 配置后缀 | 要实测的关系 |
|---|---|
| COMMAND_SIGN | 摇杆正方向希望云台朝哪个方向运动 |
| OUTPUT_SIGN | 正 CAN 电压命令是否使选定的 INS 角度增加 |
| ECD_TO_ANGLE_SIGN | 编码器 ECD 增加时，选定的 INS 角度是否增加 |

当前 Pitch 的 ECD_TO_ANGLE_SIGN 和 OUTPUT_SIGN 均为 -1，Yaw 均为 +1。
Pitch 编码器符号来自手动限位日志；带载日志已观察到正CAN输出使ECD增加、INS Pitch减小。若负反馈方向错误，回零输出检查；
不要用 COMMAND_SIGN 修复闭环正反馈。角度和速度反馈必须属于同一坐标约定。

## 单轴调参

1. 在机械中间位置、低输出限幅下选择 stage=1，左拨杆只选一轴。
2. 先确认反馈方向，逐渐给小的正/负速度目标。观察目标速度、实际速度和命令输出。
3. 先调速度 Kp，初期保持 Ki=0；需要积分时小幅增加，保留积分限幅和饱和保护。
4. 速度跟随可控后改 stage=2。进入中档应捕获当前姿态，上档小幅推杆后松开，检查保持效果。
5. 再调角度 Kp，最后双轴联调。原地不动但输出饱和，应检查方向、摩擦、重力和平衡，不能盲目加增益。

松杆的目标速度按加速度限幅减到零，因此会有一段短减速过程；完成后保持新的目标角度。
目标相对实际姿态的积累误差限制为 10°，避免机构卡住后目标不断积累。
切换 HOLD/MANUAL 会重新捕获当时姿态、清除积分。

## 限位、停机和标定

Pitch 保留已有机械端点 384、1394，向内留 100 counts，软范围为 484..1294。
根据编码器剩余行程动态限制姿态目标、趋近边界的速度，并禁止软边界处继续向外输出。
达到机械端点进入故障并零输出。零输出不能托住受重力作用的 Pitch，需要人工支撑并移回安全区。
这些软件限制依赖正确的方向配置、及时反馈和足够制动能力，不替代机械验证。

Yaw 默认允许连续多圈转动（`GIMBAL_YAW_CONTINUOUS_ROTATION=1`），不再使用
±90°软范围、±100°硬范围，不会因越过该角度减速或锁存限位故障。
INS跨±180°和编码器跨0/8191都按连续角度处理，回中减速停车后保持目标位置。
用户已确认机构无止挡且线缆不会缠绕；若移植到有限行程机构，将该宏设为0，
恢复以上电首次编码器位置为中心的±90°/±100°范围。重新使能不重定义行程中心。
Pitch端点、两轴掉线/过温/IMU异常/超时停机和显式重新准备仍保留。
多圈硬件验证步骤见[Yaw连续转动](yaw_continuous_rotation.md)。

USB ASCII 命令 `L` / `U` / `R` 后附 LF 换行，分别捕获 Pitch 下端、上端、清空端点。
仅在遥控在线、右拨杆下档、右摇杆回中、控制已退出运行且 Pitch 反馈新鲜时接受。
命令由控制任务执行，不在 USB 中断里修改控制状态。端点仅保存在 RAM，重启回到配置文件值。
捕获成功 ch23=1，ch24 返回捕获编码器值，可写入配置文件。端点应在零输出下手动轻触测量。

## 日志与故障码

USB 固定发送 VOFA+ JustFloat 48 路波形，默认 100 Hz；通讯忙时跳过发送，不阻塞控制任务。
`stream 0` / `S` 停发周期波形，`stream 1` / `T` 恢复；所有命令附 LF 换行。
停发波形不停止电机，停止输出用右下档或 `stop`（stage=0）。
角度用 deg，角速度用 deg/s，ch21 是实际控制间隔 ms。ch12 是状态，ch13 是 fault。
显示的 cmd 是驱动最近一次装入 CAN 帧的值，不代表接收端已确认执行。

状态：0=OFF，1=READY，2=HOLD，3=MANUAL，4=FAULT。

| fault 位 | 原因 |
|---|---|
| 0x01 | 遥控离线，或应用命令超过 30 ms 未刷新 |
| 0x02 | IMU 未标定、未就绪、超过 10 ms 未更新、姿态异常、速度过大；启动首秒也会出现 |
| 0x04 | 任一电机未收到反馈，或反馈超过 30 ms |
| 0x08 | 所选轴达到机械边界 |
| 0x10 | 控制间隔无效/超过 20 ms，或驱动命令看门狗触发 |
| 0x20 | 控制输入出现 NaN/Inf |
| 0x40 | 任一电机反馈温度达到 70°C |
| 0x80 | 模式、方向参数或限位配置无效 |

故障按位累积，健康反馈下显式回 OFF、摇杆回中后清除。
遥控仅接受完整、通道/开关有效的 18 字节 DR16 帧，100 ms 无有效帧为离线。
电机发送任务独立检查反馈/命令年龄；控制停止更新超过 20 ms 时不继续发送旧的非零命令。
SPI 读取失败或 BMI088 ID 校验失败不会刷新 IMU 快照时间戳。

## 代码结构与后续扩展

- `dt7_cmd.c`：遥控 → `gimbal_manual` 消息，输入与驱动解耦。
- `gimbal_control.c/.h`：无 HAL 的模式状态机、角度 P / 速度 PI、限位、平滑和积分保护。
- `2yaw_gimbal.c`：IMU/编码器快照、健康检查和 GM6020 输出适配。
- `gimbal_runtime.c`：两个机器人变体共用的入口、USB 收包队列与 VOFA+ 波形。
- `vofa_protocol.c/.h`：独立于 HAL 的 JustFloat 打包、文本命令解析和参数范围 / 单位转换。

驱动配置为 OPEN_LOOP 是为了只打包最终命令；整个云台在应用控制层闭环，不能再同时打开驱动里的 PID。
未来 DM4310 需更换输出适配和单位、重新调增益，并检查量程/模式/零位；不可直接发送这里的电压值。
未来视觉需要新增明确的角度目标接口、时序和模式仲裁；本版尚未实现视觉目标接管。
