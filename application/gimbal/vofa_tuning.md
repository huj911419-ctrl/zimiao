# 用 VOFA+ 看波形、调 GM6020 云台

当前临时上电使用 USB IMU 文本，见 [采集说明](imu_uart_capture.md)。调波形前在同一
USB 口发送 `imu 0` 并添加换行，再切换为 JustFloat；`imu 1` 可切回文本，原在线调参命令保留。

本版已经接好 USB CDC 波形和在线参数命令。你在实机上决定增益：先确认 IMU 和电机方向，
再单轴调速度 PI，最后调角度 P 和双轴。当前没有 D 项，也没有视觉目标接管。

上电默认 `stage=2`，左下档双轴、右上档遥控，回中保持角度；右拨杆 OFF 时两轴零输出。
当前直接操作与实机验证见[双轴遥控与保持](dual_hold_bringup.md)；须回中准备再显式使能。
手动传感器检查先发送 `stop` 切到0。进入波形模式后按默认100 Hz发送。在线参数仅保存在 RAM；
确认效果后，将数值写回 [集中配置](gimbal_manual_config.h)，重新编译才会成为下次上电的默认值。
Yaw/Pitch角度 Kp=8/4；Yaw速度Kp=24000、Ki=15000，Pitch速度Kp=10000、Ki=9000。
Yaw/Pitch积分限幅5000/8000、输出限幅15000/15000，满杆240/120 deg/s，
加速度720/360 deg/s²，Pitch端点余量区向内退出另限30 deg/s。
本版含运动速度前馈，回中从实测姿态/速度生成一次减速轨迹，停车后保持固定目标；
速度反馈低通为Yaw50Hz/Pitch30Hz。双轴振动处理见[说明](dual_axis_damping.md)，
最新回中逻辑与复测见[运行日志与回中停车优化](stop_profile_review.md)。

## 1. 连接 VOFA+

1. 编译 `make -j8 ROBOT=sentry` 或 `make -j8 ROBOT=infantry`，首次构建前创建 `build`。
   两个变体使用相同的云台和 VOFA+ 代码；用对应 ELF/HEX/BIN 按现有方式烧录。
2. 右拨杆下档、右摇杆回中，云台放在机械和线束中间位置；保持 IMU 静止完成上电标定。
3. 用数据 USB 线连接板载 USB CDC 接口，先用文本串口助手打开枚举出的 COM 口，
   发送 `imu 0` 并添加换行，关闭串口助手后，在 VOFA+ 选择同一 COM 口。
   串口配置可用 115200 / 8N1；这里是 USB 虚拟串口，该波特率不会把 USB 传输限制为 115200 bit/s。
4. 数据协议选 **JustFloat**，打开连接。不要选 FireWater，也不要用文本串口窗口读取波形。
5. 添加波形控件，将下面建议的通道绑定到曲线；角度、角速度、输出分别建图，避免不同单位共用一个纵轴。
   初次使用可按 VOFA+ [官方入门说明](https://www.vofa.plus/docs/learning/start/quick_start/)绑定 Y 轴并自动缩放。

固件发送固定 **48 路小端 float32 + `00 00 80 7F` 帧尾**，每帧 196 字节，
采用 [VOFA+ 官方 JustFloat 格式](https://www.vofa.plus/docs/learning/dataengines/justfloat/)。
波形模式下 USB 只发送二进制波形，命令结果也在数值通道中回传；其他固件日志走原有 RTT。
默认约 19.6 kB/s，USB 忙时丢弃本次采样，不积压曲线、不阻塞控制。
控制和传感器任务仍以约 1 ms 周期运行；100 Hz 曲线是抽样，不能完整显示高于 50 Hz 的振荡。
比较响应时同时看 ch21 的控制间隔、ch26 的发送跳过计数和 ch37 的采样时间。

## 3. 发送命令与检查回执

在 VOFA+ 发送栏使用 **ASCII / 文本发送，并附加真正的 LF 换行**，CRLF 也可。
不要使用 HEX 模式，不要把两个字符 `\n` 当作换行直接发送。命令大小写不敏感。
以下代码块每行就是一条命令，发送时逐条发送，确认 ch22 变化且 ch23=1 后再发下一条。
队列容量 8，连续批量发送的中间回执可能被后续回执覆盖。

| 命令 | 效果 | 条件 |
|---|---|---|
| `stage 0` / `stop` | 进入观测、停止两轴输出，取消更早的待处理命令 | 随时可发 |
| `imu 0` / `imu 1` | 选择 JustFloat 波形 / IMU 文本，并恢复数据流；不改变控制阶段 | 随时可发 |
| `stage 1` | 仅速度 PI，中档给零目标速度 | 遥控在线、右拨杆下档、右摇杆回中 |
| `stage 2` | 角度 P + 速度前馈 → 速度 PI，中档或上档回中保持姿态 | 同上 |
| `set yaw speed_kp 1500` | 修改 Yaw 速度 Kp，返回实际值 | 同上；其余参数语法相同 |
| `get pitch angle_kp` | 查询一个参数，结果在 ch24 | 可在运行时查询 |
| `defaults` | 恢复编译时两轴参数和默认 stage，清积分并零输出 | 遥控在线、下档、回中 |
| `stream 0` / `S` | 暂停周期波形；**电机控制仍继续** | 随时 |
| `stream 1` / `T` | 恢复周期波形 | 随时 |
| `rate 50` | 修改周期波形频率 | 仅 10 / 20 / 25 / 50 / 100 Hz |
| `L` / `U` / `R` | 捕获 Pitch 下端 / 上端 / 清空端点 | 遥控在线、下档、回中、Pitch 反馈新鲜 |

修改参数或 stage 会清除旧积分、撤销使能。命令生效后保持下档、回中，等待 READY，再使能。
编译总开关 `GIMBAL_MOTOR_OUTPUT_ENABLED=0` 时，上位机不能开启 stage=1/2。
`defaults` 不恢复在线捕获的 Pitch 端点，也不修改波形开关或频率；重启恢复配置文件端点。
L/U 成功时 ch24 返回实际捕获的编码器值，可据此写回配置文件。

| ch23 | 意义 | 怎么处理 |
|---|---|---|
| 0 | 还没有命令结果 | 检查发送栏是否附加 LF |
| 1 | 成功 | ch24 为本次生效 / 查询值 |
| 2 | 格式错误 | 检查命令、参数名、额外字符；NaN/Inf 不接受 |
| 3 | 超出范围 | 按下面参数表输入 |
| 4 | 未满足零输出调参条件 | 看 ch16=1、ch46=0、ch47=1；L/U/R 还需新鲜电机反馈 |
| 5 | 编译总输出开关关闭 | 需在配置文件开启并重新编译 |

暂停波形后，任何已处理命令都会触发一帧回执；因此 `stream 0` 本身也能看到结果。
长于 95 字符、非法字符、接收溢出或未收完的行间隔超过 250 ms 会丢弃到下一换行，
不会把残缺命令拼成参数修改。恢复时先发送一个空换行，再重发完整命令。
`stop` 依赖 USB 通信和任务调度；上板试验中仍应随手使用遥控右下档停止输出。

## 4. 哪些参数需要你调

轴名用 `yaw` 或 `pitch`。语法：`set <轴> <参数> <值>`、`get <轴> <参数>`。
下表范围是软件输入边界，不代表这些值都适合真实机构。

| 参数 | 当前默认 Yaw / Pitch | 在线允许范围 | 作用 / 固化宏 |
|---|---|---|---|
| `speed_kp` | 24000 / 10000 | 0..50000 | 速度误差对应的比例输出；`GIMBAL_*_SPEED_KP` |
| `speed_ki` | 15000 / 9000 | 0..50000 | 消除速度静差；`GIMBAL_*_SPEED_KI` |
| `angle_kp` | 8 / 4 | 0..50 | 角度误差对应的目标速度；`GIMBAL_*_ANGLE_KP` |
| `integral_limit` | 5000 / 8000 | 0..8000 | 积分输出项限幅；`GIMBAL_*_INTEGRAL_LIMIT` |
| `output_limit` | 15000 / 15000 | 两轴 1..15000 | 总输出限幅；`GIMBAL_*_OUTPUT_LIMIT` |
| `speed_dps` | 240 / 120 | Yaw 0.1..240，Pitch 0.1..120 | 满杆速度和外环速度上限；`GIMBAL_*_MAX_SPEED_DPS` |
| `accel_dps2` | 720 / 360 | Yaw 0.1..720，Pitch 0.1..360 | 手动目标速度变化限制、边界减速；`GIMBAL_*_ACCEL_DPS2` |
| `follow_error_deg` | 10 / 10 | 0.1..20 | stage=2 运动时目标角度最大积累误差；回中不覆盖保持目标；`GIMBAL_*_FOLLOW_ERROR_DEG` |

增益在内部按 **rad / rad/s** 计算；图上转成 deg / deg/s 只是为了读数。
`angle_kp` 单位是 1/s，`speed_kp` 是命令单位/(rad/s)，`speed_ki` 是命令单位/rad。
输入增益时不需要手动换算；不要直接复制采用 degree 输入的旧 PID 系数。
`integral_limit` 限制的是已经乘入 Ki 的积分输出，不是积分误差面积。
速度环抗饱和；软件仍保留超时、限位、温度、非有限值和重新准备保护。
方向、安装角、CAN ID、机械端点需要依据硬件确认，不能靠调 PID 补偿。

## 5. 按这个顺序上板

### A. stage=0 验证新 IMU

保持静止上电，先看 ch16=1、ch17=1，ch18/ch19/ch20 反馈年龄不持续增长。
手动小幅转动 Yaw，观察 ch44；手动转动 Pitch，观察 ch45。
本项目 Pitch=X、Roll=Y，若俯仰主要改变 ch40，应先修正 IMU 安装变换。
静止时 ch41..43 应接近零；转动时 gyro、角度和 ch35/ch36 的方向关系要一致。
方向确认方法与机械边界见 [上板说明](manual_bringup.md)。
BMI088 只有陀螺仪和加速度计，当前航向没有绝对方向观测；慢速 Yaw 漂移可能来自零偏，
不能仅靠加大角度 Kp 消除。

### B. 单调 Yaw 速度环

左拨杆上档只选 Yaw；未选中的 Pitch 零输出，需要支撑。右拨杆下档、摇杆回中。
先用较低的速度 / 输出限幅做方向验证，例如逐条发送：

```text
set yaw speed_dps 5
set yaw output_limit 1500
set yaw speed_ki 0
stage 1
```

这些是试验限制示例，不是已调好的 PID。确认每条回执成功，ch14=1、ch12=1，
再把右拨杆拨到上档，给小幅正 / 负速度。看 ch2/ch3、ch4：

- 目标为正、实际持续反向且输出增大：停机查反馈 / 输出方向，不继续加增益。
- 没到限位、输出未饱和、实际跟随迟缓：回下档，小幅增加 `speed_kp`，例如每轮 10%~20%，再重复同一动作。
- 反复过冲或抖动：回下档，减小 Kp；先查机构松动、IMU 噪声和采样间隔。
- 输出贴着上限仍跟不上：先查限幅、摩擦、重力和平衡；饱和时继续加 Kp 无法增加可用输出。
- Kp 合适但存在持续速度静差：再逐步加入 Ki，观察能否消除静差、是否带来低频振荡。
  小积分和输出上限同时保留；Pitch 应结合重力负载判断。

每次只改一个量；使用同一动作、同一曲线尺度比较。stage=1 中档为零速度 PI，
不锁角度；松杆后目标角度图不用于评价保持。不要把右中档误当成断电输出。

### C. 同样调 Pitch，然后进入 stage=2

回右下档、摇杆回中，左中档只选 Pitch；命令轴名改为 `pitch`，用 ch7/ch8/ch9 调速度环。
机械必须处于 Pitch 软范围内。速度环两轴都可控后，回右下档、回中，发送：

```text
stage 2
```

确认 READY 后右中档捕获当前姿态，右上档小幅推杆再松开，看角度目标 / 实际。
速度环参数暂时固定，再逐步调对应轴的 `angle_kp`：太小则恢复慢，过大可能导致角度过冲和振荡。
松杆的手动目标速度按加速度限制减到零，因此目标角度仍会短暂变化；不要把这段目标变化当成控制超调。
切换 HOLD/MANUAL 会重新捕获姿态、清积分。
两轴分别稳定后再左下档做双轴联调，比较俯仰变化前后的 Yaw 保持效果。

### D. 记录并固化

每轮记录：日期、轴、stage、8 项参数、机械负载、IMU 方向、重复操作、曲线结果。
可用 VOFA+ 的保存功能记录波形；参数用 `get` 查询 ch24，或看 ch27..34 的常用参数。
把确认的值填入 `gimbal_manual_config.h` 对应宏，再重新构建。
两轴的积分限幅、输出限幅、跟随误差已经提供各自的宏，可分别保存；在线修改不会写 Flash。
当前默认 stage=2，直接用遥控器进行角度保持与运动测试；需要始终观测的固件时将 GIMBAL_CONTROL_STAGE 改为0。
换 DM4310 后控制架构可以保留，但输出适配、限幅单位和增益必须重新确认。
