# 从只观测到遥控云台

本页是早期观测/单轴验证流程；当前默认stage=2、左下档双轴，见[双轴遥控与保持](dual_hold_bringup.md)。

当前固件上电 stage=0、两轴零输出；已删除无遥控正弦输出和固定电压输出的旁路。
USB 默认文本，USART10 同时保留。左右拨杆和右摇杆均沿用现有解码；没有改 PID，
Pitch 编码器方向沿用 -1、摇杆死区沿用 80，这些需要结合硬件反馈确认。

## 第一步：先确认遥控输入

1. 烧录前断开电机供电，避免旧自动测试固件在烧录前驱动机构；开发板保持正常供电。
2. 运行现有 VS Code “编译并烧录”，它选择 infantry。当前 Makefile 已修复；
   sentry 也可独立编译，其中 CAN1 扫描只在 USB 文本模式下一次性输出 `#` 报告。
3. 关闭 VOFA+，文本串口助手打开开发板 STM32 虚拟 COM 口，115200、8N1、
   无流控、关闭 HEX 与自动发送。同一 COM 口仅一个程序占用。
4. 打开 DT7，左右拨杆均下档、右摇杆回中。上电静止等待 IMU 初始化。
5. 收到 `# USB_IMU v2` 和 `IMU,...` 后，发送 `stop`（ASCII，行尾添加换行），
   确认应答 `result=1`、`stage=0`。电机尚未供电时电机反馈超时正常。
6. 在文本末尾观察以下字段，提供静止的表头和 3～5 行数据：

| 字段 | 左右下档、右摇杆回中时应看到 |
| --- | --- |
| stage、yaw_out、pitch_out | 0、0、0 |
| rc_online | 1；若为 0，先查遥控接收器供电、对频、UART5 RX(PD2) 接线和共地 |
| sw_left、sw_right | 2、2（下档=2，中档=3，上档=1） |
| stick_yaw、stick_pitch | 接近 0，回中落在 -80～80 内 |
| centered | 1；只表示右摇杆位于死区内 |
| request、axis_mask | 0、1（OFF、仅 Yaw） |
| valid、cal、imu_age_ms | 1、1、通常在 0～10 ms 内；序号应持续增长 |

7. 保持 stage=0，依次测试，动作间回到左右下档、摇杆回中：
   - 右摇杆仅左右移动：stick_yaw 变化；仅前后移动：stick_pitch 变化。
   - 右拨杆下/中/上：sw_right 为 2/3/1，request 为 0/1/2。
   - 左拨杆下/中/上：sw_left 为 2/3/1，axis_mask 为 1/2/3。
   - 所有这些操作期间两轴输出都应为 0。
8. 回下档、摇杆回中，再关遥控，确认 rc_online=0、request=0、输出仍为 0。
   重新开遥控，确认 rc_online 回到 1。先反馈这一轮结果，再推进电机使能。

## 第二步：确认传感器和机械方向

第一步通过后，断电接回两台电机，重新上电，仍保持 stage=0。
两台电机均保持通信，包括只测其中一轴时；观察 yaw_age_ms/pitch_age_ms 小于 30 ms，
且手转对应轴时编码器变化。手动移动、记录 IMU 的顺序见 [采集说明](imu_uart_capture.md)。

确认实物俯仰对应 INS Pitch、偏航对应 INS Yaw，以及编码器符号与配置一致。
安装变换目前全为 0，不能因为 cal=1 就认定安装方向正确；Roll 超过 ±60° 会拒绝控制。
Pitch 下/上端 384/1394、软区 484～1294 是现有配置，应重新核对，不能用旧数值强行开环。
到端点只手动托住慢移，stage=0，不需要抬到竖直或使板子准确水平。

## 第三步：只测 Yaw 速度环

实际方向、通信、限位确认后再执行本节。先支撑好没有输出的 Pitch。

1. 左拨杆下档（Yaw）、右拨杆下档、右摇杆回中，Yaw 留在软限位内。
2. 在 USB 文本模式下发送下列命令，每条带换行且确认 result=1：
   `set yaw speed_dps 5`，`set yaw output_limit 500`，`stage 1`。
   这是降低初次测试的速度/输出上限，不保证能克服摩擦；先不加 Ki。
3. 保持右下档、摇杆回中，确认 state=1（READY）、fault=0。不满足时先分析日志。
4. 发送 `imu 0`，关闭串口助手，用 VOFA+ JustFloat 打开同一 COM。
   看 ch2 目标角速度、ch3 实际角速度、ch4 实际 CAN 输出；Pitch ch9 应为 0。
5. 右摇杆回中，将右拨杆拨到上档，再缓慢给小幅左右输入。
   回中后 stage=1 给零速度，尚不保持角度。右拨杆下档应立即零输出；
   USB `stop` 会退回 stage=0，下个控制 tick 继续零输出，不会自动再次驱动。
6. 若方向相反、振动、输出持续饱和，回右下档并发 stop，保存曲线分析，不靠增加增益修正符号。

本节后再调 Yaw 速度 PI，然后验证 Pitch，最后进入 stage=2 角度保持。
stage=1/2 和在线参数仅在 RAM，重启回 stage=0，默认参数恢复。
调整参数、切阶段或切轴后必须回右下档、摇杆回中等待 READY，再使能。
遥控丢失/IMU 故障/越限会锁存停止，反馈恢复不会自动继续，必须显式回 OFF 重新准备。

## 软件验证与待完成的硬件记录

修复验证覆盖两变体完整构建、真实遥控解码与死区边界、上电超 3 秒仍零输出、
运行时 STOP 持续停机、遥控丢失停机/禁止自动恢复、USB 文本和 JustFloat 切换，
以及扫描报告的完整包发送、USB 未枚举/忙时重试、文本隔离和计数超过 255。

硬件验证待用户执行：DM-MC02、BMI088、UART5 DT7、CAN1/ID1 Yaw GM6020、
CAN2/ID2 Pitch GM6020；先记录本页第一步的静止/摇杆/拨杆/遥控断连数据，
再记录安装方向、机械限位及单轴曲线。主机模拟不能证明真实云台闭环稳定。
