## 数据从哪里来

当前接口消费UART5上已验证的18字节DBUS帧，复用现有解码器中的mouse.x/y、鼠标按钮和键盘位图。
需由支持键鼠转发的上游设备/链路把键鼠值装入这条DBUS数据流；普通遥控器摇杆能用，
不等于它已经转发了电脑键鼠。板载USB仍是CDC日志/调参，没有新增USB Host HID或PC端转发程序。
如果以后采用裁判系统0x0304、独立图传协议或PC串口，必须接对应的解码/在线检测适配器，不能直接当作DBUS。

新增 `RemoteControlGetSnapshotWithAge` 在同一临界区读取数据和有效帧年龄，避免样本与时间错配。
键鼠分支超过50ms未收到完整合法DBUS帧时置命令offline、两轴停机；短包不刷新这个时间。
原摇杆分支继续使用原100ms接收超时。上游若一直重发旧键值且保持合法帧，接收年龄无法判断电脑已掉线；
后续上游转发必须在失联时清零输入/失能，实机接入时需验证这一点。

## 将来启用时的操作

以后需要使用时再将开关改成1，重新编译并烧录；目前保持0即可。
这是编译时输入选择，不会因为移动鼠标自动抢占摇杆，也没有在线切换命令。

1. 放开全部按键和鼠标按钮，鼠标静止，右摇杆回中，右拨杆下档准备。
2. 左下档选择双轴；左中/上档仍分别选择Pitch/Yaw。鼠标静止时右拨杆上档使能。
3. 下表的按键在启用键鼠分支后才有效。键鼠不动作时，沿用当前云台控制器的减速停车与角度保持。

| 输入 | 动作 |
|---|---|
| 鼠标左右 | Yaw左右 |
| 鼠标上/下 | Pitch抬起/放下，Y正方向按常见向下约定，待实机核对 |
| Q / E | Yaw左 / 右，45°/s |
| R / F | Pitch上 / 下，30°/s |
| Ctrl按住 | 精细控制，所有速度及上限乘0.25 |
| B按住或右拨杆中档 | 保持进入时的姿态，忽略运动输入 |
| X | 两轴零输出并锁存停止；放开X不会恢复 |
| 右拨杆下档 | 两轴零输出；全部输入回中/释放后解除停止锁存并准备 |

Q+E、R+F各自抵消；键盘与鼠标运动相加后统一限速。WASD、Shift及其他按键不分配云台动作；
鼠标左右按钮也不分配动作，但按住任意按键/鼠标按钮会阻止下档准备。
键鼠启用时摇杆不叠加运动，但右摇杆仍需回中才能准备和首次使能。

默认鼠标增益：Yaw 0.25、Pitch 0.20 (°/s)/DBUS单位；键鼠上限Yaw120°/s、Pitch60°/s。
这是原始鼠标样本到角速度的映射，不是每个计数精确对应固定角度：鼠标DPI、上游报告周期与语义仍影响手感。
保持速度命令直到下一帧或超时，不在1ms任务里直接重复累加鼠标角度。
输出会继续经过现有加减速、滤波、角度保持、限位和故障保护。现有在线speed_dps缩放也继续作用，
上述默认键鼠速度按各轴配置速度/默认速度的比例缩放；修改参数后复测实际速度。
